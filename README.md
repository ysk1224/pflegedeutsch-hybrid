# PflegeDeutsch Hybrid
Original fictional clinical German language exercises for internationally trained nurses. Educational only; not clinical decision support. No real patient information. No private ICU Academy content. AI-assisted development. MIT license.

Node 22: npm install, npm test, npm run build. Copy .env.example to .env.local and supply Firebase public web config and reCAPTCHA Enterprise site key. Enable Firebase AI Logic with Gemini Developer API on Spark, configure App Check and deploy only to an authorized domain. Cloud fallback requires explicit consent. Live inference and deployment are not yet verified. No billing should be enabled.
